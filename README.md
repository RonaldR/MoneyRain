# MoneyRain :moneybag:

Money raining website: [moneyrain.nl](https://moneyrain.nl)

[![vue 3](https://img.shields.io/badge/vue-3-42b983.svg)](https://vuejs.org)

## Making it rain

- **Click / Space / →**: next gif and throw some cash, **←** goes back
- **Hold**: MAKE IT RAIN
- **P** pause, **M** sound, **R** rain on/off, **F** fullscreen, **?** help
- Rain anything you like through the url: [moneyrain.nl/?q=cats](https://moneyrain.nl/?q=cats)
- ↑ ↑ ↓ ↓ ← → ← → B A

## Development

npm install
